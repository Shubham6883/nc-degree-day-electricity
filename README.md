# NC degree days and residential electricity sales

Code, data, and results for *Two Arms of One Curve: Cooling and Heating Degree Days and Monthly Residential Electricity Sales in North Carolina, 1990-2026* by Shubham Jalan.

The study regresses monthly statewide residential electricity sales on cooling and heating degree days, with and without a time trend and calendar-month effects, and tests whether the cooling response has changed over time. All results describe associations in monthly energy (MWh). They are not forecasts and say nothing about peak power.

## Data

| File | Source |
|---|---|
| `data_raw/climdiv-cddcst-*`, `climdiv-hddcst-*`, `climdiv-tmpcst-*` | NOAA NCEI nClimDiv statewide cooling degree days, heating degree days, and average temperature (version 1.0.0, 2026-06-04 release) |
| `data_raw/eia861m_1990_2009.csv`, `eia861m_2010_present.csv` | U.S. Energy Information Administration, Form EIA-861M, monthly residential sales, customers, and price |

Both sources are U.S. federal data. The files are unmodified. North Carolina is state code 031 in the nClimDiv files.

## Layout

| Folder | Contents |
|---|---|
| `code/` | Analysis, figure, manuscript-build, and verification scripts |
| `data_raw/` | Source data listed above |

## Running it

Python 3.10 with `numpy`, `pandas`, `matplotlib`, and `python-docx`:

    pip install numpy pandas matplotlib python-docx

From inside `code/`:

    python3 validate_statlib.py    # check the distribution functions
    python3 checkpoints.py         # reproduce checkpoints from the panel and from the raw files
    python3 analysis.py            # main analysis, writes results/results.json
    python3 figures.py             # figures, writes figures/fig*.png
    python3 build_paper.py         # manuscript .docx, written to results/
    python3 verify.py              # check every number in the manuscript against the results

SciPy and statsmodels are not used. Tail probabilities come from `code/statlib.py`, and `validate_statlib.py` checks it against published critical values. `figures.py` also reads `results/annual_slopes.csv`, which is included.

Paths resolve relative to the repository, so the scripts run from any clone. Standard errors are Newey-West (Bartlett kernel, 12-month lag). Resampling uses seed 20260913.
